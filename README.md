# 🍽️ FoodFlow – Full Stack Food Ordering Application

## Overview
FoodFlow is a full-stack web application that provides a secure and scalable food ordering platform. The project focuses on modern frontend development, type safety, and secure authentication workflows using industry-standard technologies.

## Tech Stack
**Frontend**
- React.js
- TypeScript
- JavaScript (ES6+)
- HTML5, CSS3
- Zustand (State Management)
- Zod (Schema Validation)

**Backend**
- Node.js
- Express.js
- Zod (Request Validation)

**Authentication & Security**
- JSON Web Tokens (JWT)
- Email Verification System

**Tools**
- Git & GitHub
- REST APIs
- npm
- Environment Variables (.env)

## Features
- User registration and login
- Email verification for account activation
- JWT-based authentication and protected routes
- Global state management using Zustand
- Runtime and form validation using Zod
- Secure API communication
- Responsive and component-driven UI
- Modular and maintainable project structure

## Technical Highlights
- Type-safe frontend using TypeScript
- Centralized state management with Zustand
- Schema-based validation using Zod
- Stateless authentication with JWT
- Middleware-based request validation
- Clean separation of frontend and backend
- Scalable REST API design
